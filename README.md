# followup-ai

AI-powered follow-up message generator for freelancers and small businesses chasing late payments.

## Features

- Generate WhatsApp-ready follow-up messages
- Adjustable tone: friendly, firm, urgent
- Multilingual: Spanish and English
- Streaming AI responses

## Tech stack

- Next.js 16.3 + React 19.3 + TypeScript strict
- Tailwind CSS 4
- AI SDK 7 + `@ai-sdk/react`
- NextAuth.js v5 beta
- Zod 4
- Vitest 5

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start development server
- `npm run build` — production build
- `npm run lint` — run ESLint
- `npm run test` — run tests once
- `npm run test:watch` — run tests in watch mode
